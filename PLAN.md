# Milestones

1. Establish source control, upstream versions and a reproducible toolchain; verify a baseline.
2. Inspect a verifiable, supported YouTube APK and upstream patches; prove candidate fingerprints apply.
3. Implement and test the independent permutation and traversal engine.
4. Retrieve complete accessible playlists, detecting incomplete responses and cancellation.
5. Integrate playback navigation and persistence with the actual app, and verify on Android.
6. Integrate settings and user-facing progress, cancellation and failure handling.
7. Apply the official default patches and the custom patch together; verify compatibility.
8. Perform unit, statistical, integration, device, performance and security validation.
9. Sign and publish a private APK, checksum, reproducible build instructions and release evidence.

Completion requires evidence for every stage, including real app playback; tests of isolated components do not establish app integration.
