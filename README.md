# ReVanced True Shuffle

Work in progress toward a YouTube ReVanced patch for complete playlist shuffling. **This repository does not yet contain an integrated patch or an installable APK.** See [PLAN.md](PLAN.md), [STATUS.md](STATUS.md), and [VALIDATION.md](VALIDATION.md) for scope and evidence.

The target is regular YouTube for Android, with the official default ReVanced patches and non-root support. Actual compatibility, signing, installation and update instructions must be established and verified before release.
